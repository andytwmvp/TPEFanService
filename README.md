# TPEFanService

烏梅劇院偶像視角、觀眾與座位模擬、找粉絲遊戲，以及彩帶挑戰。直接開啟 [GitHub Pages](https://andytwmvp.github.io/TPEFanService/)。不需要建置；Pages 使用 `feature/ribbon-throw-game` 分支根目錄。

## 彩帶挑戰

選擇隊伍與起始成員，按「丟彩帶挑戰」。準備完成後，從 3D 畫面向上快速滑動；速度控制力度、左右傾斜控制方向。綠色是直滑命中區間、黃色是完美接取區間；方向容許值以中央力度為準，拖動時會另外用當下力度和角度預測結果。請在畫面下方開始滑動，避開按鈕與資訊面板。

從所選成員開始取同隊八人，依原站 `0、7、1、6、2、5、3、4` 順序輪替；使用 TPE 現有表演者模型，投擲時移至舞台前緣。優先找該成員的粉絲；若不可達，改試現有其他觀眾。搜尋期間不能投擲。前八投會全部完成，八投全中才進入失手即結束的挑戰輪。被別人接走算失手；落地撿取可成功但不算完美，碰撞也不算完美。

結果會保留彩帶、集合至舞台中央兩人，約 2.8 秒後可以「儲存合照」。手機若沒有自動下載，可長按產生的圖片。可提前結束、重玩或返回選單。背景切換會取消尚未完成的滑動，暫停物理、搜尋及回合時間；回來後重新滑動即可。

## 開發與驗證

```sh
npm ci
# Linux 安裝 Chromium，或設定 CHROMIUM_PATH 指向可用的 Chromium。
npm test
# Pages 部署後，直接驗證公開站（不攔截正式資源）：
node tests/pages-smoke.cjs
```

測試透過攔截 HTML 在記憶體中加入測試介面，正式檔案不暴露測試 API。流程測試停止自動 RAF，直接驅動固定步進與 visibility 事件；UI 測試使用 WebGL、Chromium 原生滑鼠／觸控輸入、桌面及手機 viewport，輸出 `tests/artifacts/`。這些測試不代表實體手機或硬體 GPU 驗收。

`ribbon-world.js` 從 TPE 畫面實際的舞台、平台、座椅、柱牆與燈具 box 網格建立空間索引。預覽、搜尋和真實投擲共用 `ribbonStepRoll`。彩帶節點以 1/120 秒固定步進運作；接取後穩定或九秒後休眠，保留幾何，只在端點移動時喚醒，鏡頭位置改變時更新展示網格。

詳細驗證與差異見 [VALIDATION.md](VALIDATION.md)，原站來源與授權狀態見 [SOURCES.md](SOURCES.md)。
